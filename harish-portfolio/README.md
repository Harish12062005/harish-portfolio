# Harish V — Professional IT Portfolio
Dark, modern, responsive portfolio for an MCA fresher.

Customize before publishing:
- Replace `your.email@example.com`.
- Replace GitHub and LinkedIn URLs.
- Replace project links with real repositories.
- Add your resume PDF and connect a download button.
- Replace the HV avatar with a professional photo if desired.

Open `index.html` to run locally. Suitable for GitHub Pages, Netlify, Vercel, or AWS static hosting.
